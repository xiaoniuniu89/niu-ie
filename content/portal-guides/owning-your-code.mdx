Your website belongs to you. There are a few ways to set things up, depending on how hands-on you want to be. You can change your mind later.

## Option 1: We look after it

Your code stays in Niu's GitHub account and we make the changes. You ask for things through this portal.

- **Good for:** most businesses. You don't need to learn anything technical.
- **You need:** nothing extra.

## Option 2: The code lives in your account

We move the code to your own GitHub account and keep working on it as a collaborator. If you ever stop working with Niu, you already have everything.

- **Good for:** businesses that want full control on paper and in practice.
- **You need:** a GitHub account. See [What GitHub is, and how to join](/portal/guides/github).
- **How:** send a feature request asking for your code to be moved, and include your GitHub username. GitHub emails you a transfer request to accept.

Your hosting (the service that puts your site online, such as [Vercel](https://vercel.com/)) can be moved to your own account in the same way.

## Option 3: You make changes yourself

With AI coding tools, people without a technical background can make small changes, like updating text or swapping photos. The AI reads the code and makes the edit when you describe what you want.

- **Good for:** people who like to tinker and want quick small edits.
- **You need:** the code in your account (option 2), and an AI tool. See [Buy an AI subscription](/portal/guides/ai-subscriptions).
- Popular tools: [Claude Code](https://claude.com/product/claude-code), [Cursor](https://cursor.com/) and [GitHub Copilot](https://github.com/features/copilot).

<Tip>
You can mix options. Many people make small text changes themselves and ask us for anything bigger. Changes are saved on GitHub, so a mistake can always be undone.
</Tip>

<Warning>
If you edit the code yourself, tell us before we start new work, so we don't both change the same thing at once.
</Warning>
