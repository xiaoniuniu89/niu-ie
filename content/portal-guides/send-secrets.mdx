Sometimes Daniel needs a password or a key to set something up: an email password, a Stripe key, an AI key. These are sometimes called **secrets** or **environment variables**.

<Warning>
Never send a password in a normal email, text or WhatsApp message, and never put one in a portal request. Those messages stay in inboxes and chat histories for years, and anyone who gets into either account can read them.
</Warning>

## Use a one-time link

[One-Time Secret](https://onetimesecret.com/en/) turns your password into a link that can only be opened once. After Daniel opens it, the secret is gone for good. You don't need an account.

1. Go to [onetimesecret.com](https://onetimesecret.com/en/).
2. Paste the password or key into the big box.
3. Optional: add a passphrase, and tell Daniel the passphrase by a different route (for example, a phone call).
4. Press **Create a secret link**.
5. Copy the link and send it to Daniel by email or message.

If Daniel says the link was already opened when he tried it, someone else saw it first. Change that password straight away and send a new link.

## Sending several at once

If you have a few keys to send, put them all in one secret, one per line, with a label on each:

```
STRIPE_SECRET_KEY=sk_live_...
GMAIL_APP_PASSWORD=abcd efgh ijkl mnop
```

## Good habits

- Where a service offers an **app password** or **API key**, send that, not your main account password. You can cancel it later without changing your login. See [Create a Gmail app password](/portal/guides/gmail-app-password).
- If you think a password has leaked, change it first, then tell Daniel.
